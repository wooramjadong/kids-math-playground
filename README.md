# 수학 놀이터: 학기별 12단계

초등 1학년 1학기부터 4학년 2학기까지 8학기 × 12단계. 정적 HTML/CSS/JS로 동작합니다.

## 한 판 20문제
- 현재 범위 15문제: 하2 · 중7 · 상6
- 앞 단원 응용 복습 5문제: 중3 · 상2
- 전체 하2(10%) · 중10(50%) · 상8(40%)
- 복습은 4·8·12·16·20번째에 섞입니다. 바로 앞 단원과 더 앞 단원의 내용을 다른 상황에 적용합니다.
- 학기 첫 단원은 이전 학기에서 복습합니다. 1-1 첫 단계는 9까지의 수 기초 응용이며 선행 단원을 가져오지 않습니다.

## 단계와 진급
1~6단계는 교과 순서. 단원이 5개인 1-1의 6단계는 교과 다지기입니다. 7~9단계 응용·연결, 10~11단계 조건 추리·역산을 포함한 사고력, 12단계 학기 종합 평가입니다.

각 단계는 연습 1판 후, 새 문제로 도전 2회를 통과해야 합니다.
- 1~11단계: 16/20 이상(80점) + 상6/8 이상
- 12단계: 18/20 이상(90점) + 상6/8 이상
- 실패해도 이전 통과 횟수나 단계는 내려가지 않습니다.
- 12단계 완료 후 다음 학기 1단계로 자동 진급. 4-2까지 마치면 전체 완료.
- 학기당 최소36판·720문제. 달력상 최소 학습일 수는 강제하지 않습니다.
- 단원 자유 연습과 다른 학기 연습은 진도·별에 반영하지 않습니다.

## 난도
상 문제는 해당 학년·단원 안에서 KMA 중상 수준을 목표로 새로 만든 추론·조건·역산·시각 문제입니다. 기출을 복제하지 않으며 공식 인증 난도는 아닙니다. 교과 전체 단원은 유지합니다.

학년별 문제: js/14-applied-1.js ~ 14-applied-4.js. 단원별 최소2가지 무작위 유형을 중·상에 맞게 심화합니다. 기존 기본 생성기도 재사용합니다. 사고력·응용 복습은 해설을 읽고 직접 다음을 누릅니다.

## 별·기록
- 80점 이상 100점 미만: 별1, 100점: 별2, 상8개 모두 정답: +1
- 하루 최대6개, 같은 단계는 하루1번. 별 한도 이후에도 진도는 진행됩니다.
- 별5개 = 카드놀이1판 유지.
- 기존 wallet/stickers/cardPlays/done/grad를 초기화하지 않습니다. 과거 resetV 표시가 없어도 지우지 않습니다.
- 새 진도는 stageProgress에 별도로 저장하며 학기별1단계에서 시작합니다. 과거 단원 만점을 새 단계 통과로 간주하지 않습니다.
- QR/링크·가족 코드 전송에 단계 진도를 포함합니다. 스티커를40/60개로 잘라 보내지 않습니다. QR 용량 초과 시 링크 복사를 씁니다.
- 브라우저 주소별 localStorage(mathplay-all-v1) 저장. 기존 주소와 브라우저를 계속 사용하세요. 가족 코드 서버 미연결 시 자동 기기간 동기화는 되지 않습니다.
