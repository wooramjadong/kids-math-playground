# 수학 놀이터 🍎📐

한국 초등 교육과정 기준 **7세 · 8세 · 3학년** 수학 게임. 설치·빌드 없이 `index.html` 하나로 동작합니다.

## 구성 (2026년 8월 = 2학기 시작 기준)

| 그룹 | 단원 |
|---|---|
| 7세 · 입학 준비 | 수 세기(9까지), 수의 순서, 가르기와 모으기, 덧셈과 뺄셈(그림), 세모·네모·동그라미, 비교하기, 규칙 찾기, 시계(몇 시) |
| 8세 · 1학년 | 50까지의 수, 100까지·10 큰 수, 10 만들기, 받아올림·두 자리 수, 상자·둥근 기둥·공 모양, 가장 긴 것, 세 가지 반복, 몇 시 30분 |
| 3학년 · 2학기 | 스피드 연산(60초), 분수 실험실(PhET 방식 탐구 + 문제), 들이와 무게 |
| 3학년 · 4학년 선행 | 큰 수 읽기(만·억·조), 각도 탐험, 규칙 찾기, 모눈 도형 빌더(넓이·둘레) |

## 특징
- 🔊 문제 읽어주기 (Web Speech API, 7·8세 기본 켜짐)
- 빨간 ○/빗금 채점, 3콤보 "참 잘했어요" 도장, 별 + 스티커판 (localStorage 저장)
- 큰 버튼 UI, 숫자판·분수 입력·모눈 그리기, 키보드 지원, 모바일/태블릿 대응

PhET Interactive Simulations의 *Fractions: Intro*, *Area Builder* 의 시각 조작 아이디어와 speed-math 류 60초 연산 게임 형식을 참고해 순수 HTML/JS로 새로 작성했습니다.
