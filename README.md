# 수학 놀이터 🍎📐

한국 초등 교육과정 기준 **7세 · 8세 · 3학년 1학기 · 3학년 2학기** 수학 게임이자, 아이의 **놀이 허브**(수학 · 영어 · 카드놀이). 설치·빌드 없이 정적 파일(`index.html`, `style.css`, `js/*.js`)로 동작합니다.

## 연결된 놀이
| 놀이 | 주소 | 조건 |
|---|---|---|
| 🔤 영어 놀이 | https://home-dun-zeta.vercel.app/ | 언제든지 (별 필요 없음) |
| 🃏 카드놀이 | https://siwon-card-nori.vercel.app/ | 별 5개 = 1판 |

새 놀이(예: 키보드 놀이)를 붙이려면 `js/6-hub.js`의 `HUB` 배열에 한 줄만 추가하면 됩니다.

## 구성 (2026년 8월 = 2학기 시작 기준)

| 그룹 | 단원 |
|---|---|
| 7세 · 입학 준비 | 수 세기(9까지), 수의 순서, 가르기와 모으기, 덧셈과 뺄셈(그림), 세모·네모·동그라미, 비교하기, 규칙 찾기, 시계(몇 시) |
| 8세 · 1학년 | 50까지의 수, 100까지·10 큰 수, 10 만들기, 받아올림·두 자리 수, 상자·둥근 기둥·공 모양, 가장 긴 것, 세 가지 반복, 몇 시 30분 |
| 3-1 · 3학년 1학기 | 세 자리 수 덧셈뺄셈, 평면도형(직각·직각삼각형·직사각형·정사각형·선분/반직선/직선), 나눗셈, 곱셈(두 자리×한 자리), 길이와 시간(mm·km·초·시각 계산), 분수와 소수(0.1) |
| 3-2 · 3학년 2학기 | 스피드 연산(60초), 분수 실험실(PhET 방식 탐구 + 문제), 들이와 무게 |
| 3-2 · 4학년 선행 | 큰 수 읽기(만·억·조), 각도 탐험, 규칙 찾기, 모눈 도형 빌더(넓이·둘레) |

모든 단원에 **🔥 심화 문제**가 한 판에 2개씩 중간(4번째·8번째 / 8문제 판은 4번째·7번째)에 섞여 나옵니다.

## 보상 규칙
- 한 판(7·8세 8문제, 3학년 10문제)을 끝내면 성적에 따라 **별 0~3개** + 스티커.
- 보너스: 끝까지 풀면 최소 별 1개 · 심화 2문제 모두 정답 +1 · 최고 기록 갱신 +1.
- **하루 상한 별 10개.** 자정(현지 날짜) 기준으로 초기화.
- **같은 단원은 하루 2번까지만** 별을 받아요. 3번째부터는 연습(별 없음).
- **내 학년 단원만** 별을 받아요. 첫 실행 때 학년을 고르고, ⚙️ 버튼으로 바꿀 수 있어요. 다른 학년은 연습 모드.
- **별 5개 = 카드놀이 1판.** 홈의 🃏 버튼을 누르면 별 5개를 쓰고 [카드놀이](https://siwon-card-nori.vercel.app/)가 새 탭으로 열려요. 별은 모아 둠다가 써도 돼요(15개 → 3판).

## 저장
모든 기록(별·스티커·오늘 횟수·내 학년)은 브라우저 localStorage에 **자동 저장**됩니다. 같은 기기·같은 브라우저에서는 계속 이어지고, 다른 기기나 시크릿 모드, 브라우저 데이터 삭제 시에는 초기화됩니다.
