## 난이도
- 한 판 = **10문제 = 하 1(10%) · 중 5(50%) · 상 4(40%)**. 첫 문제는 '하', 나머지 9문제는 중·상이 섞여 나와요.
- '중' 문제 중 일부(30%)는 서술형(문장제)으로 나와요 (`js/13-word.js`).
- 비율은 `js/5-engine.js`의 `LV_COUNT`, 단원별 문제는 `js/4c-cur-12.js`(1·2학년), `js/4d-cur-34.js`(3·4학년)의 `low / mid / high`.

## 별 규칙 (2026-10 개편)
- 80·90점 → ⭐1, 100점 → ⭐2, **🔥상 문제 4개를 모두 맞히면 +1** (한 판 최대 3개).
- 끝까지 풀기 · 최고 기록 보너스는 없어요.
- **하루 최대 6개**, **같은 단원은 하루 1번만** 별을 받아요 (별을 못 받은 판은 다시 도전 가능).
- **내 학년 단원만** 별을 받아요 (⚙️에서 설정). 다른 학기는 연습 모드.
- 단원 카드의 ⭐는 그 단원에서 받은 최고 별 수. 모든 단원 ⭐3(100점)이면 졸업장.
- **별 5개 = 카드놀이 1판** (일회용 티켓 `#p=`, `js/12-ticket.js`).
- 2026-10-29 개편 때 모은 별을 한 번 0으로 초기화했어요 (`RESET_V`, `js/1-helpers.js`). 스티커와 카드놀이 횟수는 그대로이고, 예전 단원 기록은 `doneOld`로 보관돼요.
